# Resonance

Spotify-like music streaming web app with role-based access:
User, Artist, Admin.

## Features

- Progressive audio streaming
- Artist uploads (pending admin approval)
- Role-based access control (JWT)
- Secure Cloudinary storage
- React frontend + Express backend

## Technology Stack

- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB (Atlas)
- Storage: Cloudinary
- Deployment: Vercel / Railway / Render

## Project Roadmap

1. Backend setup (Express + MongoDB)
2. Authentication & roles
3. Cloudinary integration for audio assets
4. Admin approval workflow
5. Public API for streaming
6. Frontend UI + player
7. Deployment
